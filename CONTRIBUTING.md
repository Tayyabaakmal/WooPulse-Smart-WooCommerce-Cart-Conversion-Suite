# Contributing to WooPulse Pro

Thank you for your interest in contributing to WooPulse Pro! We welcome contributions to make WooCommerce stores convert better.

## Development Workflow

1. **Fork the Repository** to your own GitHub account.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/WooPulse-Smart-WooCommerce-Cart-Conversion-Suite.git
   cd WooPulse-Smart-WooCommerce-Cart-Conversion-Suite
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Start Development Server**:
   ```bash
   npm run dev
   ```
5. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-improvement
   ```
6. **Submit a Pull Request** with a clear explanation of your changes.

## Code Standards
- Keep code clean, modern TypeScript and React.
- Ensure all WordPress generated PHP code conforms to WordPress Coding Standards (escaping, sanitization, nonces).
- Test locally before submitting PRs.
